# Dominion Financial Website

A professional website for Dominion Financial services, built with HTML, CSS, and JavaScript.

## Project Structure

```

├── src/
│   ├── index.html          # Main HTML file

│   └── images/             # Image assets folder
```

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Visual Studio or Visual Studio Code (optional, for development)

### Opening in Visual Studio

1. Clone or download this repository
2. Open Visual Studio
3. Select "Open Folder" or "Open Website"
4. Navigate to the project directory
5. Open `src/index.html` to start editing

### Viewing the Website

#### Option 1: Direct File Opening
Simply open `src/index.html` in your web browser by double-clicking the file or dragging it into a browser window.

#### Option 2: Using Visual Studio
1. Right-click on `index.html` in Solution Explorer
2. Select "View in Browser" or press `Ctrl+Shift+W`

#### Option 3: Using Live Server (Recommended)
If using Visual Studio Code:
1. Install the "Live Server" extension
2. Right-click on `index.html`
3. Select "Open with Live Server"

## Customization

### Modifying Content
- Edit `src/index.html` to change the website content
- Update text, images, and sections as needed

### Styling Changes
- Modify `src/css/styles.css` to change colors, fonts, and layout
- The CSS file includes responsive breakpoints for mobile devices

### JavaScript Functionality
- Edit `src/js/main.js` to add or modify interactive features
- Current features include:
  - Smooth scrolling navigation
  - Form validation
  - Active navigation highlighting

### Adding Images
- Place image files in the `src/images/` folder
- Reference them in HTML using relative paths: `images/your-image.jpg`

## Development Tips

### Visual Studio Features
- **IntelliSense**: Provides code completion for HTML, CSS, and JavaScript
- **Live Preview**: View changes in real-time while editing
- **Debugging**: Use browser developer tools (F12) for debugging JavaScript

### Best Practices
1. Always test on multiple browsers
2. Validate HTML using W3C Validator
3. Check responsive design on different screen sizes
4. Optimize images before adding them to the project
5. Comment your code for better maintainability
