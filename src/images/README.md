# Images Directory

Place your image assets here.

Supported formats:
- .jpg / .jpeg
- .png
- .gif
- .svg
- .webp

## Naming Conventions

Use descriptive names for images:
- logo.png
- hero-background.jpg
- service-icon-1.svg
- team-photo.jpg

## Optimization

Remember to optimize images before adding them:
- Resize to appropriate dimensions
- Compress to reduce file size
- Use appropriate format (PNG for transparency, JPG for photos)
